🔒 Política de Privacidade

Última atualização: Maio de 2026

Em resumo: Esta extensão NÃO coleta, armazena ou compartilha dados pessoais dos usuários.

1. Informações que NÃO coletamos

A extensão "Hardline Cupons" não coleta:

  • Dados pessoais identificáveis
  • Endereços de email
  • Informações de localização
  • Histórico de navegação
  • Cookies
  • Dados de dispositivo

2. Como funciona

Esta extensão funciona completamente no frontend (navegador do usuário). As únicas informações processadas são:

  • Código do cupom: Configurado pelo broadcaster e armazenado na configuração da extensão Twitch
  • Link de destino: Configurado pelo broadcaster para redirecionar usuários

Estes dados são armazenados pela própria Twitch em seus servidores, não por nós.

3. Uso de serviços terceiros

Esta extensão utiliza:

  • Twitch Extension SDK: Para integração com a plataforma Twitch (gerenciado pela Twitch)

Não utilizamos analytics, trackers ou qualquer outro serviço de terceiros.

4. Links externos

A extensão permite que broadcasters configurem links para sites externos. Não somos responsáveis pelas práticas de privacidade destes sites.

5. Segurança

A extensão é servida via HTTPS, garantindo comunicação segura. Não há backend ou banco de dados associado a esta extensão.

6. Direitos do usuário

Como não coletamos dados pessoais, não há dados para:

  • Solicitar acesso
  • Solicitar exclusão
  • Solicitar correção

7. Mudanças nesta política

Qualquer mudança nesta política será publicada nesta página com data de atualização.

8. Contato

Para questões sobre esta política de privacidade:

Email: seu.email@exemplo.com

9. Conformidade

Esta extensão está em conformidade com:

  • ✅ GDPR (Regulamento Geral de Proteção de Dados)
  • ✅ LGPD (Lei Geral de Proteção de Dados)
  • ✅ COPPA (Children's Online Privacy Protection Act)
  • ✅ Políticas de Desenvolvedores Twitch
💡 Nota importante: Esta é uma extensão minimalista focada em exibir cupons promocionais. Não há processamento, coleta ou armazenamento de dados pessoais em nenhum momento.
