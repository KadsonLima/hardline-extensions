# 🎨 Como Criar o Ícone da Extensão

## Requisitos do Ícone

- **Tamanho:** 128x128 pixels
- **Formato:** PNG com fundo transparente
- **Peso:** Máximo 1MB (quanto menor, melhor)
- **Estilo:** Simples, reconhecível mesmo em tamanho pequeno

## Opção 1: Canva (Recomendado - Gratuito)

### Passo a passo:

1. **Acessar Canva**
   - Vá para: https://www.canva.com/
   - Crie uma conta grátis (se não tiver)

2. **Criar design personalizado**
   - Clique em "Criar um design"
   - Escolha "Tamanho personalizado"
   - Digite: 128 x 128 pixels
   - Clique em "Criar novo design"

3. **Criar o ícone**
   - Use a ferramenta de texto: "Aa"
   - Digite "H" (para Hardline)
   - Escolha uma fonte bold/forte
   - Centralize o texto
   - Mude a cor para um gradiente roxo (#667eea → #764ba2)

4. **Adicionar fundo (opcional)**
   - Clique em "Elementos"
   - Busque por "circle" ou "quadrado arredondado"
   - Arraste para o fundo
   - Ajuste o tamanho
   - Aplique o mesmo gradiente

5. **Baixar**
   - Clique em "Compartilhar" → "Baixar"
   - Formato: PNG
   - ✅ Marque "Fundo transparente"
   - Baixe o arquivo

## Opção 2: Figma (Profissional - Gratuito)

1. Acesse: https://www.figma.com/
2. Crie um Frame 128x128px
3. Adicione formas e texto
4. Export como PNG

## Opção 3: Photoshop/GIMP

1. Crie documento 128x128px
2. Adicione texto/formas
3. Salve como PNG com transparência

## Opção 4: Usar um gerador online

### Favicon.io
1. Acesse: https://favicon.io/favicon-generator/
2. Configure:
   - Text: H
   - Background: Rounded
   - Font: Bold
   - Color: #667eea
3. Gere e baixe
4. Use o arquivo de 128x128px

### Hatchful by Shopify
1. Acesse: https://www.shopify.com/tools/logo-maker
2. Escolha um estilo
3. Personalize cores e texto
4. Baixe o logo

## Template Pronto (HTML para screenshot)

Se quiser criar rapidamente, salve este HTML e tire um screenshot:

```html
<!DOCTYPE html>
<html>
<head>
<style>
body {
    margin: 0;
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
    background: #f0f0f0;
}
.icon {
    width: 128px;
    height: 128px;
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    border-radius: 24px;
    display: flex;
    justify-content: center;
    align-items: center;
    font-size: 72px;
    font-weight: bold;
    color: white;
    font-family: Arial, sans-serif;
    box-shadow: 0 8px 16px rgba(0,0,0,0.2);
}
</style>
</head>
<body>
    <div class="icon">H</div>
</body>
</html>
```

Abra no navegador e tire screenshot de apenas o quadrado!

## Ferramentas para screenshot exato

### Windows:
1. **Ferramenta de Captura**
   - Win + Shift + S
   - Selecione área retangular
   - Salve como PNG

2. **ShareX** (gratuito)
   - Download: https://getsharex.com/
   - Captura com dimensões exatas

### Online:
**Screely** - https://www.screely.com/
- Cole o screenshot
- Remove fundo
- Adiciona moldura (opcional)

## Checklist do Ícone

Antes de fazer upload, verifique:

- [ ] Tamanho exato: 128x128px
- [ ] Formato: PNG
- [ ] Fundo transparente (recomendado)
- [ ] Cores vibrantes e contrastantes
- [ ] Visível/legível em tamanho pequeno
- [ ] Representa bem a extensão
- [ ] Sem texto muito pequeno
- [ ] Sem detalhes excessivos

## Dicas Importantes

✅ **Faça:**
- Use cores vibrantes
- Mantenha simples
- Use alto contraste
- Teste em tamanho pequeno

❌ **Evite:**
- Texto muito pequeno
- Muitos detalhes
- Cores muito claras
- Gradientes complexos demais

## Screenshots da Extensão (1280x720px)

Para os screenshots obrigatórios:

1. **Ative a extensão no seu canal**
2. **Abra sua página da Twitch**
3. **Pressione F11** (tela cheia)
4. **Win + Shift + S** para capturar
5. **Capture mostrando:**
   - O overlay aparecendo
   - O cupom visível
   - O painel lateral

### Editar screenshot:

1. Abra no Paint ou Photoshop
2. Redimensione para 1280x720px
3. Adicione setas/textos explicativos (opcional)
4. Salve como PNG de alta qualidade
